# Boss Gameplay Design

## Boss 定位

1. 酒吞為宴會的主人, 他將坐在高台上喝酒而後躍下與玩家戰鬥
2. 酒吞具有醉酒值, 醉酒值增加將解放新攻擊動作
3. 主要戰鬥風格為接近敵人並且進行近距離攻擊

## Boss 技能

1. 中距離快速移動
    * 地面/空中均可使用
    * Phase 1 開始使用
    * 玩家存在於範圍內, 則移動至玩家前面

2. 近距離連續攻擊A
    * Phase 1 開始使用
    * 地面/空中均可使用
    * 左右拳連擊 > 正踹 > 前踏雙手上撈重擊 > 雙手下砸重擊
    * 醉酒值達到門檻時, 追加"近距離重拳"

3. 近距離連續攻擊B
    * Phase 2 開始使用
    * 地面/空中均可使用
    * 勾拳重擊 > 踏步重拳 > 側踢 > 正踹重踢
    * 醉酒值達到門檻時, 追加"近距離重踢"

4. 近距離重拳
    * Phase 2 開始使用
    * 地面/空中均可使用
    * 前踏步重拳

5. 近距離重踢
    * Phase 2 開始使用
    * 地面/空中均可使用
    * 抬腳正踹重踢

6. 垂直下落踢擊
    * Phase 3 開始使用
    * 地面/空中均可使用
    * 跳躍 > 空中垂直下落踢擊

7. 喝酒
    * Phase 2 開始使用
    * 手持酒碟, 站立喝酒 (SuperArmor)
    * 增加"醉酒值"
    * 受到攻擊, 觸發反擊
    * "中距離快速移動" > "近距離重拳"

8. 坐地喝酒
    * Phase 1 開始使用
    * 手持酒碟, 坐在地上喝酒 (SuperArmor)
    * 增加"醉酒值"

9. 格檔
    * Phase 1 開始使用
    * 地面/空中均可使用
    * 格檔成功, 觸發"近距離重拳" "近距離重踢"

10. 抓取
    * Phase 3 開始使用
    * 地面/空中均可使用
    * 單手伸手前抓, 命中則觸發摔技演出將玩家舉起並挑釁後摔到地上

## Boss 行為

### Phase 1

1. 進入Phase 1 時, 觸發"坐地喝酒"

### Phase 2

1. 進入Phase 2 時, 觸發"喝酒"

### Phase 3

1. 酒吞HP50%以下時進入Phase 3
2. 進入Phase 3 時, 觸發"喝酒"

## 虛弱狀態

1. 進入條件: 虛弱值累積達到門檻值
2. 解除條件: 虛弱狀態持續時間結束
3. 虛弱狀態表現:
    1. 觸發"坐地喝酒"
    2. 動作持續至持續時間結束
