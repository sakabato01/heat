# Gameplay Design

## 角色系統

切換不同架式風格進行戰鬥
* 斬擊架式下為斬擊攻擊
* 黑翼架式下為近距離翼擊

---

## 普通攻擊

### ← / N / → + X

斬擊架式:  
- X1: 拔刀單手下段交叉二連斬 (Hit:2)  
- X2: 單手上段交叉二連斬 (Hit:2)  
- X3: 單手上段交叉快速連斬 (Hit:1)  
- X4: 雙手上撈重斬 (Hit:1)  
- X5: 雙手袈裟重斬 (Hit:1, Knockback)  
* Xn Recovery 允許 Xn+1 cancel  
* X1 ~ X3 Active 開始允許以下 cancel  
    * ← / N / → + Y  
    * ↑ + Y  
* X1 ~ X4 Recovery 允許以下 cancel  
    * ↑ + X  
    * ↓ + X  
* X1, X4 Recovery 允許 Jump cancel  
* X3 Recovery 允許 Dash cancel (高HT限定)

黑翼架式:  
- X1: 突進肩撞 (Hit:2)  
- X2: 跨步下踩 (Hit:2)  
- X3: 旋身二連水平翼斬 (Hit:2)  
- X4: 上段翼斜重斬 (Hit:1, Knockback)  

* Xn Recovery 允許 Xn+1 cancel
* X1 ~ X3 Active 開始允許以下 cancel  
    * ← / N / → + Y  
    * ↑ + Y  
* X1 ~ X3 Recovery 允許以下 cancel  
    * ↑ + X  
    * ↓ + X  
    * Jump  
    * Dash (高HT限定)  

---

## 跳躍攻擊

### Jump ← / N / → + X

斬擊架式:  
- X1: 拔刀單手下段交叉二連斬 (Hit:2)  
- X2: 單手上段斜斬 (Hit:1)  
- X3: 單手下劈落地斬 (Hit:1, Grounded, Slammed)  
* X1, X2 Active 開始允許以下 cancel  
    * Jump ↓ + Y  
* X1, X2 Recovery 允許以下 cancel  
    * Jump ↑ + X
    * Jump ↓ + X
    * Jump  
    * Dash (高HT限定)  

黑翼架式:  
- X1: 中下段二連側踢 (Hit:2)  
- X2: 單翼下段交叉二連翼斬 (Hit:2)  
- X3: 單翼空翻圓環下劈翼斬 (Hit:1)  
* X1 ~ X3 Active 開始允許以下 cancel  
    * Jump ↓ + Y  
* X1, X2 Recovery 允許以下 cancel  
    * Jump ↑ + X
    * Jump ↓ + X
    * Jump  
    * Dash (高HT限定)  

---
