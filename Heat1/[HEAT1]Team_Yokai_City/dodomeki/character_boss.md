# Boss Gameplay Design

## Boss 定位

1. 百目鬼將侵入大樓的監視器監視玩家並以弓箭向玩家發起狙擊
2. 當玩家進入監視器範圍內將被鎖定, 鎖定完成則百目鬼會發起狙擊
3. 玩家將需要不斷往大樓上層移動並且在頂樓與百目鬼進行戰鬥
4. 追逐百目鬼的過程中, 玩家須處理大樓中百目鬼佈下的陷阱以及大樓本身的保全機械

## Boss 技能

1. 雷箭狙擊
    * 僅在Phase 1 使用
    * 進入監視器視野內時間過長觸發
    * 監視器可被破壞
    
2. 多重射擊
    * 僅在Phase 2 使用
    * 地面/空中均可使用
    * 箭矢將留在地面
    * 向不同方向射出多發箭矢
    * Phase 3: 箭矢將帶有雷電

3. 連續射擊
    * Phase 2 開始使用
    * 地面/空中均可使用
    * 箭矢將留在地面
    * 向同一方向射出多發箭矢
    * Phase 3: 箭矢將帶有雷電

4. 引雷
    * Phase 2 開始使用
    * 地面/空中均可使用
    * 引導雷擊攻擊玩家
    * 殘留在地板的箭矢也將引導雷擊

5. 近距離攻擊
    * Phase 2 開始使用
    * 地面/空中均可使用    
    * 往前突進 > 下段踢擊 > 上段踢擊 > 後跳 
    * 攻擊動作使用拳擊, 踢擊
    * Phase 3強化
        1. 攻擊帶有雷電
        2. 攻擊新增箭矢射擊

6. 電流移動
    * Phase 3 開始使用
    * 地面/空中均可使用
    * 移動時變為電流 (Invincible)

7. 近距離帶電連打
    * Phase 3 開始使用
    * 地面/空中均可使用
    * 近距離拳腳連打

8. 格檔
    * Phase 2 開始使用
    * 格檔成功, 後跳 > "連續射擊"

## Boss 行為

### Phase 1

* 玩家往大樓高層移動
* 主要敵人
    1. 大樓監視器
    2. 詭雷陷阱
    3. 大樓保全機械

### Phase 2

* 到達大樓頂層後百目鬼出現, 進入Phase 2
* 以弓箭射擊為主要輸出

### Phase 3

* 百目鬼HP 50%時, 進入Phase 3
* 混合弓箭射擊以及近距離格鬥

## 虛弱狀態

1. 進入條件: 虛弱值累積達到門檻值
2. 解除條件: 虛弱狀態持續時間結束
3. 虛弱狀態表現:
    1. Phase 1: 不進入虛弱狀態 
    2. Phase 2: 後跳遠離玩家 > "多重射擊" > "引雷", 其後在原地直到虛弱狀態結束
    3. Phase 3: "電流移動" > "連續射擊" > "多重射擊", 其後在原地直到虛弱狀態結束
