# Heat互動

## Heat強化

X：主要快速攻擊
Y：重攻擊
B：格檔
方向＋X：方向攻擊
方向＋Y：方向性重攻擊
方向＋B：迴避／移動

X 與 Y 攻擊中可以透過 B Cancel，快速中斷攻擊並開傘格檔。

X1：三連刺擊

X2：左右斜斬

X3：轉身二連橫斬

成功格檔／成功迴避 → 可以直接進入 X3。

X4：收傘重揮

↑X：撈擊

角色向上進行撈擊。

↓X：下砸

角色以較強力的動作向下／近距離攻擊。

空中 ↑X

向上撈擊，追擊空中的敵人。
再次按 X：

角色向地面刺下。

Y1：向指定方向強力突刺

角色收著傘，朝玩家輸入的方向進行一次強力突刺。
朝指定方向進行強力突刺。

Y2：開傘震開

角色從收傘狀態打開傘，以傘面產生一次較大範圍的震開攻擊。

B｜格檔

雪女使用開傘作為格檔動作。

攻擊中可以迅速轉入開傘格檔。

目前：

X → B
Y → B
成功格檔／成功迴避 → 可以直接從 X3 進行攻擊。

反擊能量
格檔後按住 B，可以消耗反擊能量。
效果為：

在角色周圍炸出冰柱。
冰柱成功後可以銜接：

X3

或：

Y1

高 HT 時，Y1 與 Y2 攻擊過程中會生成冰晶。增加敵人的受擊硬直時間。
